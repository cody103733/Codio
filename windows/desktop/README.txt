Codio for Windows
=================

A streaming app with "Smart auto-play": pick a quality (for example 4K) and
press Play. Codio finds the best matching source by itself, and if a source
fails, doesn't start, or turns out to be lower quality than its label says,
it moves on to the next one.

Everything Codio needs is included: its own window, the mpv video player and
the interface. There is no streaming server; debrid / HTTP sources play
straight in the player. Start Codio from the Desktop or Start menu shortcut,
or run Codio.exe in this folder.

Settings has the auto-play options (quality, Mbit/s limit, source list),
subtitles, audio, player options and your account. Addons are managed in
Codio's Addons screen.

Notes
-----
- Only debrid / HTTP addon sources are played. Torrents are not supported.
- The X button closes Codio.
- Codio is free software (GPL-2.0), a modified version of the open-source
  Stremio Web interface. It is not made or endorsed by Stremio.
