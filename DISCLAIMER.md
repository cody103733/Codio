# Disclaimer

## Codio hosts no content

Codio is a media player. It does not host, store, upload, index or link to any video, music or other content, and it has no catalog of its own. Everything it plays comes from **addons**: separate services, run by third parties, that the user chooses to add. Codio ships no source or music addon. The only addons included are the official default addons that Stremio's engine brings with it (such as the Cinemeta catalog), which list titles and artwork, not streams.

Codio plays only http(s) sources. It does not use torrents or peer-to-peer sharing. It has no code to remove or get around DRM or any other copy protection.
